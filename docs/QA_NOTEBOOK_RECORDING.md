# QA บนเครื่องจริง — อัดเสียงประชุมใน ISAAC Notebook (+ กติกาลายเซ็นปิดงาน)

ต้องทดสอบหลัง build บนเครื่องจริง เพราะ Flutter web / emulator ไม่มี foreground service, background audio,
สายเข้า และหูฟัง Bluetooth ของจริง

**เตรียมก่อนเริ่ม**
- เครื่อง Android 13 ขึ้นไป 1 เครื่อง (ควรมี Android 14 ด้วย เพราะบังคับประเภท foreground service) และ iPhone iOS 17 ขึ้นไป 1 เครื่อง
- บัญชีทดสอบที่เปิดเมนู ISAAC → AI Notebook และมีสมุด "QA notebook" 1 เล่ม
- ใช้เสียงทดสอบ (อ่านข้อความ / เปิดคลิป) ห้ามอัดประชุมจริงที่มีข้อมูลลูกค้า
- เปิดแจ้งเตือนของแอป และให้สิทธิ์ไมโครโฟนตอนแอปถาม
- จดผล: ✅ ผ่าน / ❌ ไม่ผ่าน (แนบวิดีโอหน้าจอ + เวลาที่เกิด + รุ่นเครื่อง / OS)

## 9. กติกาลายเซ็นก่อนปิดงาน (ใบสั่งงาน)

ตั้งค่าบนเว็บ: ตั้งค่าใบสั่งงาน → ปิดงาน → "ต้องมีลายเซ็นทั้งช่างและลูกค้า" (`close.require_both_signatures`, ค่าเริ่มต้นเปิด)

| # | ขั้นตอน | ผลที่ต้องได้ | ผล |
|---|---|---|---|
| 9.1 | **เปิด** ค่าตั้ง · งานสถานะกำลังดำเนินการ ยังไม่มีลายเซ็น → แตะขั้น **ปิดงาน** | ขึ้น "ต้องมีลายเซ็นก่อนปิดงาน" พร้อมปุ่ม **เซ็นตอนนี้** (ผู้ให้บริการ / ลูกค้า) และ **ไปที่ส่วนลายเซ็น** — ยังไม่เรียกปิดงาน | ☐ |
| 9.2 | กด **เซ็นตอนนี้** → เซ็น → บันทึก | กลับมาที่งาน ลายเซ็นขึ้น เหลืออีกฝั่ง | ☐ |
| 9.3 | กด **ไปที่ส่วนลายเซ็น** | หน้าเลื่อนไปที่หัวข้อ "ลายเซ็น" | ☐ |
| 9.4 | งานที่มีช่องลายเซ็นตามชุด (บทบาทพนักงาน + ลูกค้า) เซ็นครบ แต่ช่องรายงาน 2 ช่องว่าง | ปิดงานได้ (นับช่องที่เซ็นแล้วเหมือนเซิร์ฟเวอร์), หัวข้อลายเซ็นขึ้น 2/2 | ☐ |
| 9.5 | **ปิด** ค่าตั้งบนเว็บ → ดึงรีเฟรชในแอป → ปิดงานที่ไม่มีลายเซ็น | ไม่บล็อก ไม่มีข้อความ "ต้องมีลายเซ็น 2 รายการ" เปิดหน้าปิดงานได้และปิดสำเร็จ | ☐ |
| 9.6 | เปิดค่าตั้งบนเว็บอีกครั้งตอนแอปยังเปิดหน้างานค้างไว้ (ค่าในแอปยังเป็นปิด) → ปิดงาน | เซิร์ฟเวอร์ตอบ 409 → แอปขึ้นข้อความ "ปิดงานไม่ได้: ต้องมีลายเซ็นทั้งช่างและลูกค้า — ยังขาด…" พร้อม **เซ็นตอนนี้** ไม่ใช่ error ดิบ | ☐ |
| 9.7 | หน้ารายการใบสั่งงาน → กดค้างที่งาน → ปรับสถานะ → ปิดงาน (ยังไม่มีลายเซ็น) | ขึ้นหน้าต่างลายเซ็นเหมือน 9.1, **ไปที่ส่วนลายเซ็น** เปิดหน้างานที่หัวข้อลายเซ็น | ☐ |
| 9.8 | เปิดงานจากหน้า "งานของฉัน" และบน iPad แบบสองช่อง แล้วทำแบบ 9.1 / 9.7 | ผลเหมือนกัน | ☐ |
