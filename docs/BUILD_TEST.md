# ทดสอบความลื่น: ใช้ release / profile ไม่ใช่ debug

ถ้าทดสอบด้วยโหมด **debug** (`flutter run` เฉยๆ, กด Run ใน IDE, `flutter build apk --debug`) แอปจะกระตุกเสมอ
เพราะโค้ดรันแบบ JIT และตรวจ assert ทุกเฟรม ทำให้ช้ากว่าแอปจริง 5–10 เท่า
โหมด debug ใช้ดูว่าฟังก์ชันทำงานถูกหรือไม่เท่านั้น **ห้ามใช้ตัดสินว่าลื่นหรือไม่**

## build ไปใช้ / ทดสอบความลื่น
```bash
flutter build apk --release --split-per-abi
```
ใช้ไฟล์ `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (มือถือ Android ส่วนใหญ่)

## วัดความลื่น (ต่อสายมือถือ)
```bash
flutter run --profile
```
- กด `P` ในเทอร์มินัลเพื่อเปิดกราฟเฟรมบนจอ
  - แถบเขียว = ลื่น
  - แถบแดง = เฟรมเกิน 16 ms
- กด `v` เพื่อเปิด DevTools → Performance แล้วอัดตอนเลื่อน / สลับแท็บ เพื่อดูว่าเฟรมไหนช้าเพราะอะไร

## ถ้ายังกระตุกบนเครื่องรุ่นเก่า
ตั้งค่า → "เอฟเฟกต์และความลื่น" → เลือก **เบา** (ปิดเบลอจริง ใช้ไล่สีแทน)
