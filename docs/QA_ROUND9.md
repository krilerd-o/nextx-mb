# QA รอบ 9 — ตรวจทั้งแอปกับ NEXTX จริง (เครื่องทดสอบ)

**วิธีทดสอบ:**
- **ระบบที่ใช้:** NEXTX backend (เวอร์ชัน 2.04.014, migrate-all + seed-standard) บน PostgreSQL 16 ในเครื่องทดสอบ
- **ตัวแอป:** แอปเวอร์ชัน Flutter web
- **การควบคุม:** ใช้ Playwright สั่งเดินทุกขั้น: เลือกเซิร์ฟเวอร์ → เข้าสู่ระบบ → เลือกบทบาท → จัดเมนู → หน้าหลัก → เมนูต่างๆ
- **ตรวจ route:** เทียบ endpoint ที่แอปเรียก (189 จุด) กับ route ใน `nextx/backend/src/routes`

## ผลรวม
- **HTTP error:** ไม่พบ 4xx/5xx จาก API ตลอดการเดินทดสอบ
- **endpoint:** ทุกตัวที่แอปเรียกมีอยู่จริงในระบบ
- **ภาพรวม:** ปัญหาส่วนใหญ่อยู่ที่ "ฟีเจอร์ยังไม่ครบ" และ "UX/ความเร็ว" ไม่ใช่ API พัง
