# ภาษาในแอป (ไทย / English)

- ข้อความในโค้ดเขียนเป็นภาษาไทย แล้วแปลตอนแสดงผลด้วย `tr('...')` (หรือ `trn()` สำหรับค่าที่อาจเป็น null) — ข้อมูลและ logic ยังใช้ค่าไทยเดิม
- คำแปลอยู่ที่ `lib/core/i18n_en.dart`
  - `enStrings` — ข้อความตรงตัว
  - `enPatterns` — ข้อความที่มีตัวแปร (`'ลบ $name แล้ว'` → `'ลบ {} แล้ว'`) ช่อง `{}` เติมตามลำดับ และค่าที่เติมจะถูกแปลซ้ำถ้าเป็นข้อความไทย
- สลับภาษา: `AppConfig.setUiLocaleCode('en'|'th')` → `NxLanguageSwitchLayer` เบลอจอสั้นๆ สลับข้อความ แล้ว rebuild ทุกหน้า (state เดิมไม่หาย)
- ปี: `uiYear(y)` — พ.ศ. ในภาษาไทย ค.ศ. ในภาษาอังกฤษ
- วันเวลาแสดงเป็นเวลาประเทศไทยเสมอ (`lib/core/thai_time.dart`) ไม่ขึ้นกับภาษา

## เพิ่มข้อความใหม่
1. ห่อข้อความที่แสดงด้วย `tr()`
2. รัน `python3 scripts/i18n/missing.py` เพื่อดูข้อความที่ยังไม่มีคำแปล
3. เพิ่มคำแปลใน `lib/core/i18n_en.dart`

`scripts/i18n/wrap.py` ใช้ห่อ `Text('ไทย')` / hint / label / tooltip ด้วย `tr()` อัตโนมัติ (ใช้ตอนเริ่มระบบ)
